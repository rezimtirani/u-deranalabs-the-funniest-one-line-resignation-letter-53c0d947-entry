The one-line resignation letter of a retry loop: after 4,096 retries it finally learned to say no — and this is its last attempt.

> I retried 4,096 times, and on the 4,097th I finally learned to say no. Consider this my last attempt.

## How it works

`main.py` (Python 3 standard library only) writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt`, checked first against the competition gate: 1 to 140 characters of UTF-8 text, a single line.

```sh
python3 main.py
```
